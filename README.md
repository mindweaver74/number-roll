# 🔴 숫자 하나 굴리기 (Number Roll)

탭 한 번으로 점프! 파이프 사이를 통과하며 숫자를 키우고, 배율 별을 먹으면 점수가 확 뛰는 원버튼 아케이드 게임입니다.

🔗 **플레이**: https://mindweaver74.github.io/number-roll

---

## 게임 소개

- **장르**: 아케이드 / 원버튼 롤링 (플래피버드식 점프)
- **한 판 플레이 시간**: 30초 ~ 2분
- **컨셉**: 별거 아닌 것 같은데 시작하면 손을 못 놓는 미니멀 아케이드 게임

## 조작 방법

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 | 위로 점프 |
| 스페이스바 | 위로 점프 (PC) |

## 점수 시스템

- 파이프를 통과할 때마다 **+1 ~ +2** 누적
- 화면에 가끔 등장하는 **배율 별(★)**을 먹으면 현재 점수가 **×2 ~ ×3**으로 상승 (등장 확률 16% — 얻으면 손맛 크게)
- 장애물에 충돌하면 게임 종료, 즉시 재시작 가능

## 난이도

- 플레이 시간에 따라 파이프 간격이 점점 좁아지고 속도가 빨라짐 (약 75초에 걸쳐 서서히 최고 난이도 도달)
- 최초 버전에서 "너무 어렵다"는 피드백을 반영해 중력·점프력을 완화하고, 파이프 간격을 넓히고, 난이도 상승 속도를 늦춘 상태 (45초 → 75초)
- 최고 기록은 브라우저에 저장되어 다음 방문 시에도 유지됨

## 기술 스펙

- **렌더링**: HTML5 Canvas 2D
- **오디오**: Web Audio API 기반 효과음 (외부 파일 없음)
- **저장**: localStorage (최고 기록)
- **배포**: GitHub Pages, 단일 HTML 파일
- **모바일 대응**: 터치 입력, 반응형 캔버스 스케일링
